# Wanwusheng Golden Examples

These examples are conditional references, not default prompt content.

Use them only when the user asks to reference, compare, improve, or validate the
Wanwusheng prompt format. Learn only the writing structure, information density,
shot granularity, fixed-position logic, visible performance cues, and final-frame
continuity. Never reuse their characters, locations, plots, dialogue, props,
color palettes, lighting, camera choices, or exact blocking in an unrelated script.

The current script's content fact lock, user director notes, and accepted video
final frame always have higher priority than these examples.

## Example 1: Indoor Multi-Character Confrontation

```text
【[STYLE LOCK]
35mm 家庭现实主义胶片质感，低饱和旧暖灰色调，细腻颗粒，浅景深，客厅顶灯的微弱暖光混合窗外深蓝夜色。城市家庭客厅空间，沙发、茶几和碎裂花瓶形成高位区域、分界线和低位对峙区域。画幅 2.39:1，严格按照原剧本顺序和导演分镜执行，不额外改写镜头，不添加新剧情，不生成字幕，不配 BGM。

音轨：仅室内空调低噪、茶杯轻碰声、人物脚步声、碎瓷片轻响、人声对白，不配 BGM。

[记忆性固定站位 - 最高优先级]
本段是新场景第一段，重新建立固定站位。

沙发位于画面后方，是许文涛的高位区域；茶几位于客厅中央，是双方的空间分界；碎裂花瓶位于茶几右侧地面。
许沉站在茶几左前方，身体朝向方琳，保持克制保护妹妹的姿态。
许宁站在许沉左后侧，身体略微缩向哥哥，面朝方琳。
方琳站在茶几右侧靠近碎花瓶的位置，面对许沉和许宁，保持指责姿态。
许文涛坐在沙发右侧，暂时不移动，视线在许宁和方琳之间来回。

除非剧本文字明确写出移动，人物不得换边、不得瞬移、不得改变前后关系。

[参考锚点]
@[{许沉形象图}] 作为许沉身份和表演状态锚定，控制压怒、护住妹妹、说话前短暂停顿的状态。
@[{许宁形象图}] 作为许宁身份和表演状态锚定，控制受指责后的紧张、委屈和依赖哥哥的状态。
@[{方琳形象图}] 作为方琳身份和表演状态锚定，控制强势指责、嘴角绷紧、目光持续逼视的状态。
@[{许文涛形象图}] 作为许文涛身份和表演状态锚定，控制犹豫、偏向方琳但暂时不愿直接冲突的状态。
@[{许家客厅图}] 作为空间锚定，锁定沙发、茶几、碎花瓶、门口和人物前后关系。
@[{客厅色卡图}] 作为色彩锚定：旧暖白墙面、深灰沙发、暗木茶几、冷蓝窗光、碎瓷片白色反光、压抑暗部。

镜头一：
中景平拍，先建立客厅空间关系。方琳站在茶几右侧，指向地上的碎花瓶；许宁站在许沉身后，许沉挡住她半步；许文涛坐在沙发上观察。方琳嘴角绷紧，指尖连续指向碎花瓶，声音带着逼迫感。

方琳说：“花瓶是她碰碎的！”台词必须一字不改。

HARD CUT

镜头二：
过方琳肩拍许宁近景。方琳肩膀虚焦在前景，许宁抬眼看她，嘴唇张开后又抿住，吸气停顿半拍，随后解释。

许宁说：“我没有，是你刚才推到桌边的！”台词必须一字不改。

HARD CUT

镜头三：
过许沉肩拍许文涛近景。许文涛仍坐在沙发上，视线先看碎花瓶，再看许宁，眉心压低，声音偏向劝许宁认错。

许文涛说：“小宁，先跟阿姨道个歉。”台词必须一字不改。

HARD CUT

镜头四：
许沉近景，轻微俯拍。许沉侧身挡在许宁前方，嘴唇压成直线，眼神先落到父亲脸上，再移向墙边的监控位置，声音克制但明显不服。

许沉说：“爸，先别急着让她认错，看看桌边的监控。”台词必须一字不改。

HARD CUT

镜头五：
碎花瓶特写。碎片散落在茶几右侧地面，方琳的手指从画面上方伸入，指尖停在碎片旁边。只拍碎花瓶和方琳的手，不新增台词。

HARD CUT

镜头六：
方琳近景。她先看一眼墙边监控，再迅速把视线压回许沉，嘴角向一侧扯紧，抬手挡住监控方向，语气变得尖锐。

方琳说：“看什么监控？碎了就是她赔！”台词必须一字不改。

末帧：
方琳仍站在茶几右侧，许沉和许宁保持在茶几左侧，许沉挡在许宁前方；许文涛仍坐在沙发上；碎花瓶留在茶几右侧地面，为下一段许沉要求查看监控、许文涛起身阻拦做衔接。

[负面约束]
NOT 人物换边；NOT 许宁提前离开许沉保护范围；NOT 许文涛提前起身；NOT 监控画面提前出现；NOT 碎花瓶消失；NOT 添加路人；NOT 修改台词；NOT 生成字幕或屏幕文字；NOT 描述人物服饰；NOT BGM；无水印。

视频时长：15秒。
】
```

## Example 2: Neutral Care Scene Without Power Hierarchy

```text
【[STYLE LOCK]
50mm 克制医疗现实主义质感，低饱和灰绿色与米白色调，细腻自然颗粒，浅景深，诊室顶灯的均匀冷白光混合窗外阴天散射光。社区卫生室空间，诊疗床、靠背椅、饮水机和办公桌形成清晰的照护动线与视线关系，不强行设置高低权力层级。画幅 2.39:1，严格按照原剧本顺序和导演分镜执行，不额外改写镜头，不添加新剧情，不生成字幕，不配 BGM。

音轨：仅室内空调低噪、饮水机加热声、纸杯轻响、椅子摩擦声、人物呼吸声、人声对白，不配 BGM。

[记忆性固定站位 - 最高优先级]
本段是新场景第一段，重新建立固定站位。

诊疗床位于画面右后方，靠背椅位于画面中央，饮水机位于画面左后方。
林妍蹲在靠背椅左侧，身体朝向周伯，保持扶稳他的姿态。
周伯坐在靠背椅上，身体略微前倾，双手放在膝盖上。
护士小唐站在办公桌和饮水机之间，面朝周伯，准备取水和查看血压记录。

人物之间没有高低权力关系，重点保持照护动作和视线方向连续。

[参考锚点]
@[{林妍形象图}] 作为林妍身份和表演状态锚定，控制担心但保持稳定、动作轻柔、持续观察周伯状态的表演。
@[{周伯形象图}] 作为周伯身份和表演状态锚定，控制头晕后的虚弱、呼吸变浅、眼神努力保持清醒的状态。
@[{护士小唐形象图}] 作为护士小唐身份和表演状态锚定，控制专业、冷静、动作准确的状态。
@[{社区卫生室图}] 作为空间锚定，锁定诊疗床、靠背椅、饮水机、办公桌和人物动线。
@[{卫生室色卡图}] 作为色彩锚定：米白墙面、灰绿色窗光、冷白顶灯、浅灰地面、透明饮水机反光、低饱和木色桌面。

镜头一：
中景平拍，建立卫生室空间。周伯坐在靠背椅上身体前倾，林妍蹲在他左侧扶住他的手臂；护士小唐从饮水机方向回头观察。周伯抬眼，视线短暂失焦。

林妍说：“周伯，先坐稳，别急着起来。”台词必须一字不改。

HARD CUT

镜头二：
周伯面部近景。周伯嘴唇微微分开，眨眼变慢，呼吸短而浅，视线从林妍脸上移向桌面。

周伯说：“我就是眼前有点发黑。”台词必须一字不改。

HARD CUT

镜头三：
护士小唐手部和半身特写。她拿起纸杯倒入温水，另一只手扶住杯底，确认水量后转身递给林妍。只拍动作和道具，不新增台词。

HARD CUT

镜头四：
双人近景。林妍接过纸杯，身体仍保持在周伯左侧，没有改变站位。她把杯口递到周伯嘴边，眼神停在周伯脸上。

护士小唐说：“血压有点高，先喝两口温水。”台词必须一字不改。

HARD CUT

镜头五：
林妍和周伯双人近景。周伯小口喝水，喉结轻轻移动；林妍没有催促，只用手掌稳定住杯底，嘴角收紧，呼吸跟着周伯的节奏放慢。

林妍说：“慢慢来，呼吸跟着我。”台词必须一字不改。

末帧：
周伯仍坐在靠背椅上，身体由前倾稍微恢复稳定；林妍仍蹲在他左侧，手中保持纸杯；护士小唐站在饮水机和办公桌之间查看记录，为下一段护士测量血压、林妍继续陪伴做衔接。

[负面约束]
NOT 设置高位或低位权力关系；NOT 周伯突然站起；NOT 林妍换到周伯另一侧；NOT 水杯提前消失；NOT 添加病房人员；NOT 夸张痛苦表演；NOT 修改台词；NOT 生成字幕或屏幕文字；NOT 描述人物服饰；NOT BGM；无水印。

视频时长：12秒。
】
```

## Example 3: Moving Corridor And Spatial Continuity

```text
【[STYLE LOCK]
35mm 城市楼道现实主义质感，冷灰傍晚色调，细腻颗粒，浅景深，楼道窗户的蓝灰自然光与住户门内的局部暖光交错，金属电梯门和楼梯扶手产生冷硬反光。老居民楼门口、狭窄走廊和电梯口形成一条明确的移动路线，人物从入户门方向连续移动至电梯口。画幅 2.39:1，严格按照原剧本顺序和导演分镜执行，不额外改写镜头，不添加新剧情，不生成字幕，不配 BGM。

音轨：仅楼道环境低噪、拖鞋脚步声、门锁碰撞声、信封纸张摩擦声、电梯提示音、邻居开门声、人声对白，不配 BGM。

[记忆性固定站位 - 最高优先级]
本段是新场景第一段，重新建立固定站位。

韩峥和韩宁位于画面右后方的入户门附近，电梯口位于画面左前方，楼梯扶手位于画面右侧前景。
韩峥站在韩宁前方半步，肩上背着黑色挎包，身体朝向电梯口。
韩宁紧跟在韩峥身后，身体朝向电梯口，始终处于韩峥保护范围内。
赵阿姨从右后方的另一户门口出现，沿走廊追向韩峥和韩宁，不能突然出现在电梯口前方。

[参考锚点]
@[{韩峥形象图}] 作为韩峥身份和表演状态锚定，控制急于离开、保护妹妹、边走边压住情绪的状态。
@[{韩宁形象图}] 作为韩宁身份和表演状态锚定，控制紧张、回头确认追赶者、依赖哥哥的状态。
@[{赵阿姨形象图}] 作为赵阿姨身份和表演状态锚定，控制急切追赶、试图拦住两人的状态。
@[{居民楼走廊图}] 作为空间锚定，锁定入户门、楼道窗、电梯口、楼梯扶手、走廊深度和移动路线。
@[{信封图}] 作为道具锚定，锁定牛皮纸信封的形状、材质和手部传递关系。
@[{走廊色卡图}] 作为色彩锚定：冷灰墙面、蓝灰窗光、深棕门框、旧米色地面、金属电梯灰、门内微弱暖黄光。

[人物背后背景锁定]
韩峥背后背景随着移动从入户门、走廊墙面逐步变化到电梯口，不得切回室内客厅。
韩宁背后保持韩峥身体、走廊墙面和楼梯扶手的连续关系。
赵阿姨背后保持她实际经过的住户门口和走廊墙面，不得瞬移到电梯另一侧。

镜头一：
从楼梯下方低机位拍摄小全景，前景下三分之一被台阶遮挡。韩峥牵着韩宁从右后方入户门走向左前方电梯口，韩宁回头看了一眼身后的赵阿姨。只拍脚步和移动关系，不新增台词。

HARD CUT

镜头二：
侧面中景，镜头与韩峥和韩宁保持平行移动。韩峥始终在韩宁前方半步，赵阿姨从后方门口追出来，三人的前后距离保持连续。

赵阿姨说：“韩峥，你先等等！”台词必须一字不改。

HARD CUT

镜头三：
过韩宁肩拍韩峥近景。韩宁肩膀在前景虚焦，韩峥一边走一边回头半秒，随后把视线转回电梯方向，手臂轻轻向后护住韩宁。

韩峥说：“我没时间解释，到了楼下再说。”台词必须一字不改。

HARD CUT

镜头四：
韩宁面部近景，镜头仍保持走廊移动方向。她的视线越过韩峥肩膀看向后方，眼睛短暂睁大，嘴唇抿紧，脚步变快半拍。

韩宁说：“哥，她追过来了。”台词必须一字不改。

HARD CUT

镜头五：
信封手部特写。赵阿姨从后方伸手抓住信封一角，韩峥没有停下，只把信封收回胸前，三人的移动方向保持向左前方电梯口。

赵阿姨说：“把信封留下，我只看一眼。”台词必须一字不改。

HARD CUT

镜头六：
电梯口侧面中景。韩峥和韩宁已经到达电梯前，韩峥站在电梯按钮左侧，韩宁站在他身后；赵阿姨停在距离两人两步的位置，没有越过韩峥。韩峥转身面对赵阿姨，走廊深处仍在画面右后方。

韩峥说：“信可以给你，路别再挡着。”台词必须一字不改。

末帧：
韩峥站在电梯按钮左侧，韩宁站在他身后，赵阿姨停在两步之外；牛皮纸信封仍在韩峥手中；电梯门位于画面左侧，走廊和入户门位于右后方，为下一段赵阿姨继续解释、韩峥决定是否交出信封做衔接。

[负面约束]
NOT 人物瞬移；NOT 改变移动方向；NOT 赵阿姨提前出现在电梯口；NOT 韩宁跑到韩峥前面；NOT 背景切回室内；NOT 电梯口和入户门位置互换；NOT 越轴；NOT 信封提前掉落；NOT 添加路人；NOT 修改台词；NOT 生成字幕或屏幕文字；NOT 描述人物服饰；NOT BGM；无水印。

视频时长：15秒。
】
```
